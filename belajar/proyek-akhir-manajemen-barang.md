# Proyek Akhir - Manajemen Barang

Buat aplikasi CLI dengan fitur:

1. Melihat semua barang.
2. Menambahkan barang.
3. Mencari barang berdasarkan nama.
4. Mengubah stok.
5. Menghapus barang.
6. Membaca data saat program dimulai.
7. Menyimpan data kembali ke JSON.

## Urutan pengerjaan

1. Buat `struct Barang`.
2. Buat fungsi membaca JSON.
3. Buat fungsi menampilkan barang.
4. Tambahkan menu dengan `match`.
5. Tambahkan input pengguna.
6. Tambahkan fitur tambah, cari, ubah, dan hapus.
7. Tambahkan fungsi menyimpan JSON.
8. Uji setiap fitur dengan beberapa data.

## Target kemampuan

Proyek ini menggabungkan variabel, percabangan, perulangan, fungsi, `Vec`,
`String`, ownership, struct, error handling, file, dan JSON.
