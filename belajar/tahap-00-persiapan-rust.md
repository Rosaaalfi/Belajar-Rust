# Tahap 0 - Persiapan Rust

Proyek ini menggunakan Cargo. Jalankan perintah berikut dari folder proyek:

```powershell
cargo run
cargo check
cargo fmt
cargo build
```

- `cargo run` menjalankan program.
- `cargo check` memeriksa error tanpa membangun executable final.
- `cargo fmt` merapikan format kode.
- `cargo build` membangun program.

Biasakan menjalankan `cargo check`, `cargo fmt`, lalu `cargo run` setelah
mengubah kode.

## Target

- Mengenal terminal.
- Mengenal struktur proyek Cargo.
- Bisa menjalankan program Rust.
